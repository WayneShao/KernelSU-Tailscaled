# KernelSU-Tailscaled v2.1.0

English by default, with Simplified Chinese retained and Headscale sign-in
available directly from the module WebUI. These are backward-compatible
features, so this is a minor release rather than a patch or major release.

## WebUI language

- Default to English regardless of the device language.
- Use **Language → 简体中文** in any page header to switch to Simplified Chinese.
  The selection is remembered in that WebView; when storage is disabled, it
  lasts for the current session only.
- Translate dashboard labels, actions, confirmations, update screens and
  notices. Raw engine diagnostics and log messages remain untranslated.

## Headscale and custom control servers

Under **Sign in / Headscale**, enter a server base URL such as
`https://headscale.example.com`, choose **Connect / sign in**, and confirm.
Open the returned sign-in link and follow your server's registration
instructions, then refresh status. If the link is still pending, use
**Open full panel** to finish signing in. Leave the server field blank to use
the official Tailscale service.

- Persist the server preference across restarts without resetting hostname,
  DNS, routes or other preferences.
- Require confirmation before changing servers. Switching can disconnect the
  current network and requires registration on the selected server; do it
  locally, not over a Tailscale-only remote session.
- Accept HTTP and HTTPS base URLs without credentials, query parameters or
  fragments. HTTPS is recommended; HTTP is unencrypted.
- Return registration URLs only through the explicit sign-in action. Ordinary
  status and log output continue to redact authentication URLs.
- Require an enabled module and running daemon; complete any pending legacy
  migration and explicitly enable it before signing in.

## Upgrade

Install the universal, ARM or ARM64 ZIP through KernelSU Manager. Existing v2
identity and configuration are retained; no new migration is required. Reopen
Details after updating to load the new WebUI. No script requests an Android
reboot.

The bundled official Tailscale engine remains at 1.104.2. Module version 2.1.0
uses `versionCode=20000018`, increasing from 20000017 in 2.0.5.
