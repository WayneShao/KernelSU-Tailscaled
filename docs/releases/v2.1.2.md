# KernelSU-Tailscaled v2.1.2 — bioluks fork

Combined release from **all-features-merged**: English-default WebUI, optional
Simplified Chinese, Headscale sign-in, lower idle supervisor CPU, and Taildrop
receiving fixes. Based on WayneShao/KernelSU-Tailscaled, with upstream credits
and BSD-3-Clause licensing retained. This is a rooted-Android Tailscale module,
not a device-specific kernel or an official Tailscale/KernelSU release.

## Install or switch from upstream

- **Recommended:** `KernelSU-Tailscaled-v2.1.2.zip` includes ARM and ARM64.
- `KernelSU-Tailscaled-arm64-v2.1.2.zip` is the smaller ARM64-only download.
- `KernelSU-Tailscaled-arm-v2.1.2.zip` targets 32-bit ARM.
- Install through KernelSU Manager. GitHub's autogenerated source archives are
  not module installers.

Install in place over an existing `kernelsu-tailscaled` module. The module ID and
`/data/adb/kernelsu-tailscaled` directory are unchanged; login, preferences,
configuration and queued files are retained. **Do not uninstall or delete state
first.** Reopen Details to load the updated UI. No script requests an Android
reboot, logout, control-server change or engine upgrade.

The first switch from upstream is a **manual ZIP install**. Later module updates
use **bioluks/KernelSU-Tailscaled**. Version code **20000021** advances past the
private `2.1.1-dev.1` combined build (20000019). Legacy `magisk-tailscaled`
identities still require the explicit migration procedure in the README.

## Included changes

- **Language:** English by default regardless of device language. Use
  **Language → 简体中文** in any page header; the choice is remembered in that
  WebView. Raw engine diagnostics and logs remain untranslated.
- **Headscale:** under **Sign in / Headscale**, enter the server's base URL,
  choose **Connect / sign in**, confirm, then open the registration link. Blank
  selects official Tailscale. HTTPS is recommended. Changing servers can
  disconnect the existing network; do this locally, not over a Tailscale-only
  remote connection.
- **Idle CPU:** reduce repeated process inspection, Android property lookups and
  redundant Manager metadata work. Process recovery and pending-install integrity
  checks remain active; detailed network diagnostics run on demand. Earlier
  isolated Android profiling measured about 95% less supervisor CPU, not a
  battery-life guarantee.
- **Taildrop:** explicitly initialize the private persistent inbox in native and
  userspace modes. Files queue under `/data/adb/kernelsu-tailscaled/files/` and
  survive restarts. Retrieve with the module CLI's `file get /sdcard/Download`;
  files are not automatically copied into Downloads. See the README for exact
  CLI/socket commands. Headscale must advertise file sharing.
- **Build tools:** patched development-only Vite/Vitest and affected transitive
  dependencies; the release dependency audit reports no known vulnerabilities.
- **CI recovery test:** wait for the replacement panel's listening socket, not
  merely its PID. Delayed listener startup is exercised explicitly. Runtime code
  is unchanged by this test correction. The unpublished `v2.1.1` candidate tag
  remains untouched after its CI failure; this release uses a new tag.

The bundled official Tailscale engine remains **1.104.2**.

## Verification and limits

Local validation covers 153 Linux contract/lifecycle tests, including delayed
panel recovery, 69 frontend tests, 18 browser scenarios, frontend type checking
and build, ShellCheck, package manifests and reproducible ZIPs. The packaged
ARM64 daemon and CLI have also been exercised in isolated userspace mode.
GitHub Actions repeats the release gates before publication, verifies package
bytes, and checks release immutability and asset attestations.

The merged development runtime was exercised on a OnePlus 9 Pro (LE2123), with
identity/preferences retained and the language selector and Headscale field
checked. The Taildrop fix was separately verified on Android with SELinux
enforcing, bidirectional transfer, restart persistence, and a 3.36 GB file with
matching SHA-256. A later merged-install transfer was blocked by the Mac's
control/peer connectivity; it is not claimed as passed.

ARM packages lack equivalent on-device coverage. Broad Magisk/APatch support,
all Headscale configurations, long-term network stability and screen-off
battery life are not established. No official KernelSU store approval is claimed.
