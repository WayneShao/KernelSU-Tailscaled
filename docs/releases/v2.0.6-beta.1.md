# KernelSU-Tailscaled v2.0.6-beta.1

Compatibility beta for Issue #1. **Not a stable release.**

## Fixes

- Older-kernel route discovery: retry without NETLINK_GET_STRICT_CHK only for
  unsupported-option errors; preserve permission failures.
- Android control-plane DNS: use the Android dnsproxyd resolver in dnscache's
  forwarder instead of accidentally querying loopback DNS.
- Report outbound-interface discovery errors rather than binding sockets to lo.

## Engine and installation

Bundles a project-built, modified **Tailscale 1.104.4-kst1**, not an official
Tailscale binary. Pinned source, patch and rebuild instructions are committed
under `engine/compat`; upstream license is included in the ZIP.

Install the universal ZIP (or the matching ARM/ARM64 ZIP) through your module
manager. Existing identity/configuration is retained by the normal installer;
installation restarts the module service, not the device. Do not add hosts
entries or copy a default route into the main table for this test.

This beta temporarily pins its compatibility engine: WebUI can check official
versions but cannot download/apply them and accidentally erase the fix. Existing
same/older official overrides are preserved but ignored; a newer external
engine blocks installation before the old service is stopped. Do not manually
downgrade or delete engine state to bypass that safeguard.

Stable feed/store stays on **v2.0.5**. This beta is opt-in, not Latest.

## Verification and limits

- Pristine 1.104.4 reproduces both route-binding and control-DNS failures.
- Patched actual upstream code passes unsupported/supported strict checking,
  Android DNS, combined failures, interface-change and route-recovery cases.
  Permission-denied/no-route cases fail explicitly, not by binding to lo.
- Full native daemon obtains a fresh login URL, completes isolated test-control
  authorization and reaches Running with a native TUN.
- Module unit/install/rollback tests, frontend tests, desktop/mobile browser
  tests, shell checks, package verification and deterministic ZIP build are
  required before publication.

The isolated test environment is not a complete replica of the reporter's ROM.
The exact Android 13 / kernel 4.19 / SukiSU device and ARM hardware behavior
still need beta feedback. No claim of that device being fixed is made yet.
