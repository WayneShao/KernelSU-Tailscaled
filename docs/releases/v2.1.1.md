# KernelSU-Tailscaled v2.1.1 — bioluks fork

The combined release from **all-features-merged**: English by default, optional
Simplified Chinese, Headscale sign-in, lower idle supervisor CPU, and Taildrop
receiving fixes. Based on WayneShao/KernelSU-Tailscaled, with upstream credits
and BSD-3-Clause licensing retained. This is a rooted-Android Tailscale module,
not a device-specific kernel or an official Tailscale/KernelSU release.

## Install or switch from upstream

- **Recommended:** `KernelSU-Tailscaled-v2.1.1.zip` includes ARM and ARM64.
- `KernelSU-Tailscaled-arm64-v2.1.1.zip` is the smaller ARM64-only download.
- `KernelSU-Tailscaled-arm-v2.1.1.zip` targets 32-bit ARM.
- Install the ZIP through KernelSU Manager. Do not use GitHub's autogenerated
  source-code archives as module installers.

Existing `kernelsu-tailscaled` installations can install this ZIP in place.
The module ID and `/data/adb/kernelsu-tailscaled` directory are unchanged;
existing login, preferences, configuration and queued files are retained. Do
not uninstall or delete state first. Reopen Details to load the updated UI.
No installer script requests an Android reboot.

The first switch from upstream is a **manual ZIP install**. After that, module
updates use **bioluks/KernelSU-Tailscaled**, not upstream. Version code
**20000020** also upgrades the private `2.1.1-dev.1` combined build (20000019).
Legacy `magisk-tailscaled` identities still require the explicit migration
procedure in the README; the fork does not change module IDs automatically.

## Included changes

### English and Chinese

The WebUI defaults to English regardless of the device language. Use
**Language → 简体中文** in any page header to switch; the choice is remembered in
that WebView. Raw engine logs and diagnostics remain untranslated.

### Headscale

Under **Sign in / Headscale**, enter your server's base URL, choose
**Connect / sign in**, confirm, and open the registration link. Leave the field
blank for official Tailscale. HTTPS is recommended. Switching servers can
disconnect the current network and requires registration on the selected
server; do this locally, not over a Tailscale-only remote connection.

### Idle supervisor CPU

Reduce repeated process inspection, Android property lookups and redundant
Manager metadata work. Process recovery remains active before login; detailed
network diagnostics run on demand. Pending-install integrity checks remain in
place. Earlier isolated Android profiling measured about 95% less supervisor
CPU; this is not a battery-life guarantee.

### Taildrop

Pass the private persistent state directory explicitly to tailscaled in native
and userspace modes. The inbox is queued under
`/data/adb/kernelsu-tailscaled/files/`, separate from the existing login state.
Retrieve files with the module CLI's `file get /sdcard/Download`; they are not
automatically copied into Downloads. Headscale must advertise file sharing.
The README contains the exact CLI and socket commands.

The bundled official Tailscale engine remains **1.104.2**. No kernel replacement,
logout, control-server change or engine upgrade is performed by this release.
