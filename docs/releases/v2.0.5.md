# KernelSU-Tailscaled v2.0.5

Fix standalone Android control-plane connectivity and update the official
Tailscale engine directly from the module WebUI.

## Android connectivity

- Bundle official Tailscale 1.104.2, including upstream standalone Android DNS,
  network monitoring, and CA support.
- Native Android mode selects the official interface-binding implementation
  (`TS_FORCE_LINUX_BIND_TO_DEVICE=true`). Control and UDP sockets no longer
  depend on an absent main-table default route for marked traffic. No copied
  default routes, hard-coded control hosts, or patched engine binaries.
- Restrict login DNS diagnostics to actual login states; ordinary startup is
  no longer treated as evidence of a fresh-login DNS failure.

## Update the engine from WebUI

Open **Tailscale engine update** in the module dashboard, check for an official
stable release, download and verify it, then explicitly apply it. Downloading
alone leaves the running service untouched. Applying briefly restarts the
module's service; it does not reboot Android or require signing in again.

- ARM and ARM64 downloads use the official HTTPS stable server and published
  SHA-256 checksum, with bounded downloads and restricted archive extraction.
- Activation preserves identity and configuration, validates service recovery,
  and restores the previous engine/state if activation fails.
- Interrupted transactions recover on the next lifecycle operation. A later
  stop or disable is respected; recovery does not silently override it.
- Separately updated engines survive module updates and boot; a newer bundled
  engine takes precedence. Downgrades are rejected by the normal updater.

## Validation

- Real Xiaomi test: temporarily ran 1.102.3, then checked, downloaded, verified,
  and applied 1.104.2 using the same controller actions as WebUI. The running
  executable changed to the downloaded engine; identity/configuration stayed
  unchanged, and public peer connectivity recovered. Normal runtime restored.
- OnePlus: updated engine retained across a module reinstall and authorized
  reboot, with automatic service activation.
- Automated coverage includes checksum/archive rejection, rollback, interrupted
  activation, disabled/stopped intent, and browser check/download/apply flow.
- See `docs/verification/2026-10-22-release-2.0.5.md` for evidence and limits.

The reporter's exact ROM and complete fresh-account browser authorization are
not yet verified. ARM32 packages are checked, but phone runtime testing is ARM64.

## Install

Install the universal or architecture-specific ZIP through KernelSU Manager.
Existing v2 identity and configuration are retained. Reopen Details after an
update to load the new WebUI. The withdrawn beta.1 is not a supported release.
